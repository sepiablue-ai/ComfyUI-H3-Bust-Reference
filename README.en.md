# ComfyUI-H3-Bust-Reference

[日本語](README.md)

A ComfyUI node that selects one of six upper-body three-view reference images for MiniMax H3 Ref2VA and adds an English role definition to your prompt. The numbers 01–06 identify assets, not measured cup sizes. This is a discrete selector, not continuous interpolation. Results depend on the model, clothing, character reference and prompt.

## Installation

Start with a ComfyUI installation that can already run a standard MiniMax H3 Ref2VA workflow. This node does not set up the full video-generation environment. The manual installation below does not depend on a ComfyUI-Manager listing.

1. Download and extract this repository using GitHub's Code menu, or clone the URL shown there.
2. Place `__init__.py`, `nodes.py` and `assets` directly inside `ComfyUI/custom_nodes/ComfyUI-H3-Bust-Reference/`. Avoid nested extraction folders.
3. Restart ComfyUI and add **H3 Bust Reference Selector**, under `MiniMax-H3/Bust Reference`.

The node uses PyTorch, NumPy and Pillow from your existing ComfyUI Python environment. It does not install packages or download models automatically.

## Sample requirements

`sample_workflow_three_view.json` is a ComfyUI UI workflow, not an API prompt.

- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) with `MiniMaxH3ReferenceToVideo`, `MiniMaxH3SigmaShift` and the `minimax` CLIP type.
- [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes) with `MiniMaxLowVRAMAttention` and `MiniMaxChunkFeedForward`.
- The five weights below and an adult character image you have permission to use. These are not bundled.

See the [ComfyUI model conversions](https://huggingface.co/Kijai/MiniMax-H3_comfy) and [official MiniMax H3 repository](https://huggingface.co/MiniMaxAI/MiniMax-H3). Check the terms for your chosen weights. Locations are relative to ComfyUI's `models/` folder.

| Type | Sample filename | Folder |
|---|---|---|
| Ref2VA model | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` | `diffusion_models/` |
| Text encoder | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `text_encoders/` |
| Video VAE | `minimax_h3_video_vae_int8_convrot.safetensors` | `vae/` |
| Audio VAE | `minimax_h3_audio_vae_fp32.safetensors` | `vae/` |
| Four-step LoRA | `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors` | `loras/` |

The sample uses a LoRA filename without a subfolder to avoid OS-specific path separators. If your LoRA is already in a subfolder, reselect it from the loader's dropdown. Reselect the other models to match your installation too. Arbitrary replacement models and LoRAs may require different settings.

To share models from another installation, configure the **running ComfyUI's** `extra_model_paths.yaml` or use `--extra-model-paths-config`. Restart/refresh model lists after adding weights.

## Usage

1. Drag the sample JSON into ComfyUI.
2. Upload and select your character image in the initially empty `LoadImage` node.
3. Check and, if necessary, reselect all five model files.
4. Choose `bust_size` 01–06, edit `base_prompt`, then run.

```text
LoadImage.IMAGE ------------------> H3 Ref2VA.ref_image_0 (<Picture 1>)
H3 Bust Reference Selector.IMAGE -> H3 Ref2VA.ref_image_1 (<Picture 2>)
H3 Bust Reference Selector.PROMPT -> H3 Ref2VA.prompt
```

Set `ref_image_slot` to `ref_image_1`. It controls the text label only; it does not inspect or change connections. **Connect images contiguously from `ref_image_0` without gaps.** H3 numbers the images actually supplied, in order, starting at `<Picture 1>`.

The sample uses 832×1408, 124 frames, 24 fps, four steps and a fixed seed. VRAM, RAM and runtime requirements depend on your environment. Videos are saved under `output/H3-Bust-Reference/`.

## Node behavior

| Input | Meaning |
|---|---|
| `bust_size` | Discrete asset choice 01–06; no interpolation |
| `ref_image_slot` | `ref_image_0`–`ref_image_8`; default `ref_image_1` |
| `base_prompt` | Non-empty H3 prompt |
| `mode` | Only `Three-View Turnaround`; retained for older calls |

Outputs: `IMAGE` (RGB float32, `[1,H,W,3]`, values 0–1) and `PROMPT` (string). The role definition targets an adult woman identified as `<Subject 1>`.

The role is inserted after `subject_definitions:`, or under a new heading at the beginning. Existing custom definitions for the selected picture are preserved. Only exact known sentences generated by earlier versions are upgraded. Other picture definitions are never removed. Delete obsolete references from old workflows manually.

For old UI workflows with different widget ordering or output counts, recreate the node and reconnect it.

## Troubleshooting

- **Missing/red nodes:** check startup logs, installation layout, H3 support and KJNodes.
- **Model not in list:** check names, directories and shared-path configuration; reselect from the dropdown.
- **Missing image:** select a character image in LoadImage; keep all six `assets/bust/bust_XX_3view.png` files installed.
- **SaveVideo input errors:** update ComfyUI; if needed, recreate SaveVideo, connect the CreateVideo output and set format and codec to auto.
- **Unexpected proportions:** check labels, connections and definitions; compare the influence of clothing and the character reference.

## Validation

Configuration was reviewed against local ComfyUI 0.36.0 and KJNodes 1.5.2; these are not guaranteed minimum versions. CPU tests cover all six images, prompt preservation, legacy sentence upgrades, invalid inputs and workflow connections. On Windows with an RTX 4070 (12 GB), the sample was converted to API format and used to generate one clip each for sizes 01 and 06, with the same character image, seed and settings. Both outputs passed full decoding: 832×1408, 124 frames, 24 fps, with audio. The sample now contains the tested 2D anime prompt in which the character turns from front to side view.

The test selected a local character image and LoRA path; users must select their own image and installed models in the distributed workflow. Other operating systems, clean installations and browser interaction with the distributed JSON remain untested. Assess the visible proportion difference and visual quality by watching the outputs.

Run `python -m unittest -q test_nodes.py` using the ComfyUI Python environment. Tests do not generate videos or use the GPU.
